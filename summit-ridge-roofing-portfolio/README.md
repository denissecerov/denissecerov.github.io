# Summit Ridge Roofing — Portfolio Website

A responsive, single-page roofing company concept built as a front-end portfolio project.

## Features
- Responsive desktop/tablet/mobile layout
- Fixed navigation with mobile menu
- Hero estimate form
- Services section
- Recent project gallery
- Step-by-step process section
- Customer testimonials
- Full contact form
- Scroll reveal animations
- Demo form submission toast
- Accessible labels and semantic HTML

## Run locally
Open `index.html` directly in a browser.

## Portfolio note
This is a fictional business concept. The phone number, email, reviews, and company details are placeholders for demonstration purposes.

## Image attribution
The demo uses remotely hosted Unsplash images. Replace them with locally hosted images before deploying if you want the site fully self-contained.
